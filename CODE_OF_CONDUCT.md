# Código de conducta

## Nuestro compromiso

Nosotros, como comunidad, queremos ofrecer un entorno abierto, respetuoso y seguro para todas las personas que participen en este proyecto.

## Normas esperadas

- Ser respetuosos, constructivos y profesionales
- Aceptar críticas razonables y mejorar el proyecto de manera colaborativa
- Mantener un lenguaje apropiado y evitar comentarios ofensivos o discriminatorios
- Centrarnos en la calidad del trabajo, no en la persona
- Ayudar a que el proyecto sea accesible y acogedor

## Comportamiento inaceptable

No se tolerarán:

- insultos, acoso o amenazas
- comentarios xenófobos, sexistas, homófobos o de cualquier tipo discriminatorio
- mensajes de odio, intimidación o acoso repetido
- conductas que impidan una colaboración sana y constructiva

## Aplicación

Las decisiones sobre conducta se tomarán de forma justa y proporcional. Cuando se detecte un comportamiento inaceptable, se podrán aplicar medidas como:

- aviso privado
- requerimiento de corrección
- expulsión temporal o permanente del proyecto

## Contacto

Si necesitas reportar una situación de este tipo, contacta con el responsable del proyecto o con la persona designada por el equipo.
